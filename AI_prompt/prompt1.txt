### 1. BACKEND (`main.py`) REQUIREMENTS

- **Framework:** FastAPI + Uvicorn
- **CORS:** Allow all origins (for local development)
- **In-memory AUDIT_LOG:** A list that stores all agent actions
- **Endpoints:**
  - `GET /api/v1/health` → `{"status": "Overmind OS Online", "timestamp": "..."}`
  - `POST /api/v1/task` → Accepts JSON `{"prompt": "...", "user_id": "..."}`. Returns a `task_id` immediately and runs the workflow in the background using `BackgroundTasks`.
  - `GET /api/v1/audit-log` → Returns `{"logs": AUDIT_LOG, "count": len(AUDIT_LOG)}`
- **Workflow (simulated multi-agent execution):**
  The background task must log the following events in this exact order (with 1-2 second sleeps between each):
  - `Orchestrator | BOOT | SUCCESS | "Agent initialized with prompt: '...'"`
  - `Orchestrator | PARSE_TASK | SUCCESS | "Task decomposed into subtasks."`
  - `Research-Agent | SEARCH_WEB | PENDING | "Searching for relevant data..."`
  - `Research-Agent | SEARCH_WEB | SUCCESS | "Found 3 relevant sources."`
  - `Writer-Agent | GENERATE_TEXT | PENDING | "Drafting executive summary..."`
  - `Writer-Agent | GENERATE_TEXT | SUCCESS | "Summary: [text]"`
  - `Email-Agent | SEND_EMAIL | BLOCKED | "Action held for human approval per Overmind Policy."`
- Each log entry structure: `{"id": uuid_hex[:8], "timestamp": ISO UTC, "agent_name": ..., "action": ..., "status": ..., "details": ...}`
- Use Pydantic models for request validation.
- Add print statements for live terminal logs.
- The server must be runnable with: `uvicorn main:app --reload --port 8000`
